Privacy policy

Your files stay under your control.

This policy describes the personal EEE Backup desktop workflow and this information website.

Purpose and data accessed

EEE Backup is operated by the owner of the TheBaron0 GitHub account for personal backups. It reads the locally selected EEE study folder and uses the Google Drive API to create, read and maintain an encrypted Restic repository in the owner’s Drive. The configured Drive permission can technically access other Drive files; the backup workflow targets its dedicated repository.

Storage and encryption

Restic encrypts file contents and backup metadata on the computer before uploading them. Google Drive stores the encrypted repository. Repository object names, sizes and request timing may still be visible to Google. The repository encryption password and Google authorization tokens are stored locally in files restricted to the owner’s account. They are not collected by this website.

Use and sharing

Google account access is used only to operate the owner’s backup repository. Backup data is not sold, used for advertising, or shared with other people by the configured workflow. Google processes the Drive data as the selected storage provider under its own policies. This website contains no backup data, Google access tokens or encryption passwords.

Retention and control

Backup snapshots are retained until the owner chooses to remove them. This setup does not automatically delete older versions. Revoking Google access stops future authorized access but does not automatically remove existing backups.

The owner can review or revoke access through Google Account permissions. Existing repository data can be removed separately from the owner’s Google Drive if desired. Source files on the computer remain separate from the backup repository.

This website

This static website has no sign-in form, upload feature, analytics script or advertising code. Its hosting provider may process ordinary connection and access logs under its own privacy policy.

Contact and changes

For questions, use the public contact options on TheBaron0’s GitHub profile. Changes to the workflow may require updates to this policy. Last updated: 6 November 2026.
